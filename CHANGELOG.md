# Changelog

## Desktop 1.1.0 — 2026-11-02

- First open-source desktop release with the shared cinema interface and 6,454-video catalog.
- Native application menus, system-browser playback and native JSON backup dialogs.
- Persistent local library with atomic writes; compatible Chrome backup import/export.
- Sandboxed renderer, isolated preload, fixed local asset protocol and bounded network bridge.
- macOS arm64 smoke test and packaging; automated macOS, Windows and Linux release builds.
- MIT code license, retained ODC-By data attribution, privacy and contribution documentation.

## Chrome 1.1.0

- Dark cinema interface, HN evidence, local recommendations and JSON backups.
- Manifest V3 with storage permission and HackerTube API host access.
